# AutoFix - Sistema Web de Gestión de Mantenimiento Automotriz

## Descripción
Single Page Application (SPA) desarrollada para la gestión integral de un taller mecánico. Permite registrar solicitudes de mantenimiento y administrar órdenes de trabajo mediante operaciones CRUD completas en memoria RAM (Rúbrica AD01 - Instituto Cordillera).

## Tecnologías Utilizadas
* **HTML5 & CSS3:** Diseño responsive con Flexbox y CSS Grid.
* **Bootstrap 5 & SweetAlert2:** Interfaz limpia y modales de confirmación.
* **Vanilla JavaScript (ES6+):** Arquitectura modular (`import`/`export`) y gestión en memoria con Arrays y `Map`.
